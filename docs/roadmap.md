# Roadmap

Volatile project state. CLAUDE.md holds stable orientation; this file holds what changes:
current status, what is done, what is open, and the next milestone. The /status command
reads this file and verifies it against the repo, so keep it current as work lands.

This is a template. Replace the sections below with your project's real state.

## Current status

One line on the active milestone and where it stands.

## Done

- Item, with the file or artifact it produced.

## Open items

- Item, nearest first, with the run instruction or prompt that carries it.

## Next milestone

The next milestone and its goal.
